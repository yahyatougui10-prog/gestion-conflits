# Project: Gestion des Conflits - Comic Book Presentation
## Installation
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser at `http://127.0.0.1:5000`

## Controls
- **Next Slide**: `ArrowRight`, `ArrowDown`, `PageDown`, `Space`, mouse wheel down, or `SUIVANT` button
- **Prev Slide**: `ArrowLeft`, `ArrowUp`, `PageUp`, mouse wheel up, or `PRÉCÉDENT` button
- **Jump to Slide**: Keys `1-9` and `0` (for 10), clicking a progress dot, or the `☰` menu
- **Overview Menu**: Press `M` or the `☰` button
- **First/Last Slide**: `Home` / `End`
- **Fullscreen**: Press `F` or the ⛶ button
- **Sound Effects**: Press `S` or the 🔊/🔇 button (comic "pops" on slide changes)
- **Help**: Press `?`, `H`, or the `?` button
- **Close Overlays**: `Escape`
- **Mobile**: swipe left/right to navigate
